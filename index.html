Forma — AI Body Coach

Full-stack web app · Camera + AI · Subscriptions

Forma is a fitness coach in your browser. It works out your body numbers, builds a food and training plan around your goal, and includes Mo, an AI coach you can chat with. You can snap a photo of your plate and Mo estimates the calories and macros.

The demo below runs in your browser with example data (tap "Explore with example data"). The AI features need the server, which isn't deployed publicly yet.

  • Body numbers: body fat (US Navy tape method), muscle score (FFMI), BMR, and a daily burn that recalibrates from your logs.
  • Food camera & AI scans: calories from a meal photo, and a body-fat estimate from front, side and back photos, using the Claude API.
  • Training & progress: a weekly program with exercise how-tos, a guided camera for progress photos, and a before/after slider.
  • A real product, not just a demo: accounts and a database with row-level security so each user's data and photos stay private (Supabase), three plans with Stripe subscriptions, and daily AI limits enforced on the server so costs stay under control.
  • Tested: server tests that run the real API code against fake Stripe, Supabase and Claude services.

Crystal Rush Simulator (Roblox)

Multiplayer game · Roblox Studio · Luau

A mining simulator: players break crystals, sell them for coins, upgrade their pickaxe and backpack, and unlock five zones, each harder and more valuable than the last. Rebirthing resets progress in exchange for a permanent coin multiplier.

  • World built from code: the whole map (zones, gates, rocks, crystals) is generated by script, with crystals placed so they keep their distance and never block the doorways.
  • Cheat-resistant: the server checks every hit (distance to the crystal, cooldown, unlocked zone, bag space), so the client can't fake coins.
  • Saving: progress is stored with DataStores, autosaves every 90 seconds, and won't overwrite a save that failed to load.
  • Game balance in one place: all costs, health and rewards use formulas in a single config file, so the game can be rebalanced without touching the logic.
  • Polish: HUD, floating numbers, sparks, sounds, mouse and touch controls, and optional Game Passes for monetization.
